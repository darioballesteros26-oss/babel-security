POLÍTICA DE PRIVACIDAD Y TÉRMINOS DE USO

VERSIÓN 2.0 · JUNIO 2026

1. QUIÉN SOMOS

Babel Security es un software de cifrado y traducción de documentos desarrollado por Darío Ballesteros. Contacto: darioballesteros26@gmail.com

2. ARQUITECTURA ZERO-KNOWLEDGE

Babel Security opera bajo un principio de conocimiento cero absoluto. Ni el desarrollador ni ningún tercero puede acceder a tus documentos, claves de cifrado, o datos personales en ningún momento.

3. DATOS QUE RECOPILAMOS

Datos que NO recopilamos: documentos, contraseñas, claves de cifrado, contenido de archivos, metadatos de documentos.

Datos que SÍ recopilamos: número de serie del hardware para validación de licencia, versión del software instalada.

4. CIFRADO Y SEGURIDAD

Todos los archivos se cifran con AES-256-GCM. Las claves se derivan mediante Argon2id y HKDF-SHA256. Ninguna clave abandona tu dispositivo en ningún momento.

5. LICENCIA DE USO

El software se licencia por dispositivo mediante validación de hardware. La licencia es personal e intransferible. Queda prohibida la ingeniería inversa, redistribución o uso comercial sin autorización expresa.

6. LIMITACIÓN DE RESPONSABILIDAD

Babel Security no se responsabiliza de pérdida de datos por contraseña olvidada, daños derivados del uso incorrecto, pérdida de la frase de recuperación BIP39, o incompatibilidades con sistemas operativos de terceros.

7. GDPR

Babel Security cumple con el RGPD. Al no recopilar datos personales procesables, el usuario es el único responsable del tratamiento de los datos que almacena.

8. TRADUCCIÓN OFFLINE

El motor de traducción opera 100% offline. Ningún texto es enviado a servidores externos.

9. JURISDICCIÓN

Esta política se rige por la legislación española. Cualquier disputa se someterá a los tribunales de Marbella, España.
