Política de Privacidad

Última actualización: agosto 2026 · Responsable: Darío Ballesteros Sánchez · darioballesteros26@gmail.com

1. Datos que recopilamos

Esta web no utiliza cookies ni herramientas de analítica de ningún tipo. No rastreamos tu navegación ni recopilamos datos automáticamente al visitar esta página.

Los únicos datos que recibimos son los que tú nos envías voluntariamente a través del formulario de contacto: nombre, email y descripción del problema. Estos datos se usan exclusivamente para responder a tu solicitud y no se comparten con terceros bajo ningún concepto.

2. Software Security Babel

Security Babel, como aplicación de escritorio, no recopila ni transmite tus documentos ni su contenido a ningún servidor. Todo el procesamiento —cifrado, traducción, almacenamiento— ocurre localmente en tu dispositivo.

3. Arquitectura zero-knowledge

Babel Security opera bajo un principio de conocimiento cero absoluto. Ni el desarrollador ni ningún tercero puede acceder a tus documentos, claves de cifrado o datos personales en ningún momento. Todos los archivos se cifran con AES-256-GCM; las claves se derivan mediante Argon2id y HKDF-SHA256 y nunca abandonan tu dispositivo.

4. Uso de datos de Gmail

La aplicación accede a la cuenta de Gmail del usuario únicamente cuando este activa voluntariamente la función de correo integrado, mediante autorización OAuth 2.0 explícita concedida por el propio usuario a través de los servidores de autenticación de Google. Sin dicha autorización, Babel no tiene acceso a ningún dato de la cuenta de Google.

El acceso se limita exclusivamente a permitir que el usuario lea, redacte, envíe, archive y organice sus propios correos desde dentro de la aplicación Babel. La integración funciona como una extensión del propio cliente de correo del usuario, no como un servicio que analiza o procesa esos datos de forma independiente o con fines propios.

Babel no utiliza el contenido de los correos del usuario para ningún otro propósito. La aplicación no analiza los correos del usuario, no los indexa en servidores externos, no los usa para entrenar modelos de inteligencia artificial y no los comparte con terceros bajo ningún concepto.

Todo el contenido de correo se procesa y almacena localmente en el dispositivo del usuario, cifrado con las mismas medidas de seguridad aplicadas al resto de documentos gestionados por Babel (AES-256-GCM). Ningún correo ni metadato asociado sale del dispositivo del usuario en ningún momento.

El usuario puede revocar el acceso de Babel a su cuenta de Google en cualquier momento, tanto desde la propia aplicación Babel como desde la configuración de seguridad de su cuenta de Google en myaccount.google.com/permissions.

5. Declaración de uso limitado (Google API Services)

El uso que Babel hace de los datos obtenidos mediante los Servicios de API de Google se atiene estrictamente a la Política de Datos de Usuario de los Servicios de API de Google (Google API Services User Data Policy), incluyendo los requisitos de uso limitado (Limited Use requirements).

En concreto: los datos obtenidos de Gmail se usan exclusivamente para proveer la función de correo electrónico integrado dentro de la aplicación Babel, a solicitud expresa del usuario. Babel no utiliza dichos datos para servir publicidad de ningún tipo. Babel no transfiere, vende ni cede los datos obtenidos de la API de Google a terceros. Babel no usa los datos de la API de Google para desarrollar, entrenar o mejorar modelos de inteligencia artificial, ni para ningún fin ajeno a la función de correo expresamente solicitada por el usuario.

6. Tus derechos

Puedes solicitar en cualquier momento acceder a los datos que nos hayas enviado por el formulario, corregirlos o solicitar su eliminación, escribiendo a darioballesteros26@gmail.com.

7. Jurisdicción

Esta política se rige por la legislación española y el Reglamento General de Protección de Datos (RGPD).
